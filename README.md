# 🧠 MIT 6.006 — Introduction to Algorithms

This repository contains my **solutions to the problem sets** from the [MIT 6.006: Introduction to Algorithms] course.

---

## 📚 Overview

MIT 6.006 is one of the foundational computer science courses focusing on the **design and analysis of efficient algorithms** and the **mathematical principles** behind them.

The problems are implemented primarily in **Python**, covering topics such as:
- Sorting and searching
- Binary search trees and heaps
- Graph algorithms (BFS, DFS, Dijkstra)
- Dynamic programming
- Hashing and amortized analysis
- Divide and conquer
- Shortest paths and greedy algorithms
